# 프렙 카페 운영 기록

## 실행

Node.js 20 이상이 설치된 환경에서 프로젝트 폴더에서 실행합니다.

    node server.mjs

브라우저에서 http://127.0.0.1:4173 을 엽니다. 별도 패키지 설치는 필요하지 않습니다.

## 저장 방식

샘플 자료는 데이터/매장운영데이터.json에서 읽습니다. 새 판매와 재고 기록, 샘플 판매 수정·삭제 내용은 현재 브라우저의 로컬 저장소에 저장됩니다. 같은 브라우저에서 다시 열면 유지됩니다. 다른 기기와 공유되는 서버 저장 기능은 포함하지 않습니다.

## 구현 범위

docs/04_개발계획.md의 EPIC 1–3을 구현합니다. 비용 기록 편집, 데이터 가져오기·내보내기, 자동 발주량 계산, 사용자 계정과 배포는 이번 범위에 포함하지 않습니다. 테스트 진행 상황과 사용자 확인 결과는 docs/05_테스트결과.md에 기록합니다.
