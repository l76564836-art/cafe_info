## 개발 중 검사 결과

### 자동 검사

- JavaScript 구문 검사: src/app.mjs, src/operations.mjs, server.mjs 통과.
- 샘플 자료 건수: 메뉴 8개, 재료 11개, 레시피 22개, 판매 6,112건, 비용 3,560건, 재고 변동 1,515건, 초기 재고 11건 대조 통과.
- 기준 자료 ID와 레시피의 재료 참조 검사 통과. 메뉴·재료·판매 ID 중복 없음.
- 원본 판매 6,112건 모두 순매출이 수량 × 단가 − 할인액과 일치하며, 판매 당시 재료비·포장비 스냅샷이 있음.
- 2 × 4,000원 − 200원 = 7,800원, 수수료 120원 별도 반영 확인.
- 예시 원가(잔당 재료비 500원·포장비 100원)로 공헌이익 6,480원, 이익률 약 83.1%, 비용 1,000원을 뺀 손익 5,480원 확인.
- 예시 판매 수량을 2개에서 3개로 바꾸면 순매출 11,800원, 직접 원가 1,800원, 수수료 120원, 공헌이익 9,880원, 비용 1,000원을 반영한 손익 8,880원 확인.
- 재고 예시의 실사 전 잔량 1,270g, 실측 1,260g, 조정 −10g, 실사 후 잔량 1,260g 확인.
- 원가 자료 누락은 공헌이익을 0원으로 계산하지 않고 미완성으로 처리하며, 판매 기록이 없는 기간은 판매 0원으로 표시하지 않음.

### 브라우저에서 확인한 샘플 값

| 화면·기간 | 순매출 | 직접 원가 | 수수료 | 비용 기록 | 기록 기준 손익 |
|---|---:|---:|---:|---:|---:|
| 일일 기록 · 2026-09-18 | ₩671,900 | ₩171,951.7 | ₩10,080 | ₩211,000 | ₩278,868.3 |
| 월 실적·손익 · 2026-09-01~18 | ₩13,968,930 | ₩3,546,642.3 | ₩209,565 | ₩3,798,010 | ₩6,414,712.7 |

2026년 9월은 18일까지의 부분 기간으로 표시한다. 9월 19일은 샘플 판매 기록이 없는 날짜로 표시하고 판매액을 0원 실적으로 확정하지 않는다. 월비용계획은 위 손익에 더하지 않는다.

2026-09-18 샘플 잔량 계산 화면도 확인했다. 재료 11종이 표시되고, 원두 4,280g·우유 23,180ml 등 잔량은 초기 재고, 입고·폐기·실사, 판매 레시피 사용량을 반영한다.

### 브라우저 입력 확인

- 판매 기록 창에서 날짜·메뉴·채널·수량·단가·할인·수수료 입력란이 표시됨.
- 예시 입력 2개, 단가 4,000원, 할인 200원, 수수료 120원에서 미리보기가 순매출 7,800원·수수료 120원으로 계산됨.
- 판매액보다 큰 할인액 입력은 저장을 막고 안내함. 이 확인 과정에서는 기록을 저장하지 않음.
- 재고 변동 입력 창과 필수 재료 목록이 표시됨.
- 모바일 폭에서 페이지 본문 가로 넘침을 수정한 뒤 뷰포트 가로 스크롤 없이 표시됨.

## 범위와 제한

- 비용 기록 입력·수정·삭제는 개발 계획에 따라 후속 범위로 두었다. 손익은 제공된 비용 기록 3,560건을 사용한다.
- 사용자 로그인, 다중 기기 서버 저장, 엑셀 가져오기·내보내기, 백업·복원, 자동 발주량 계산, 외부 배포는 포함하지 않는다.
