# 프렙 카페 운영 기록·분석 웹 프로그램 FRD

- 문서 상태: PRD 범위 및 계산 기준 반영본
- 기준 문서: docs/01_PRD.md
- 작성일: 2026-09-28
- 구현 전제: 이 FRD는 기능 요구를 설명한다. 화면 시안은 가상 예시이며 실제 저장·계산 동작의 기준이 아니다.

## 전체 사용 순서와 기능 목록

1. 영업일 또는 조회 기간을 선택한다.
2. 판매·비용 기록을 입력·수정·삭제한다.
3. 판매량에 레시피를 적용해 재고 차감을 반영한다.
4. 메뉴별 수익성을 확인한다.
5. 일·월 손익을 확인한다.
6. 입고·폐기·실사 기록과 재료 잔량을 확인한다.
7. 기록을 저장하고 갱신된 결과를 확인한다.

MVP 기능은 영업일·기간 선택, 판매·비용 기록 관리, 메뉴별 수익성, 일·월 손익, 재고 변동·실사·잔량, 데이터 저장·검증이다. 수업 후 기능은 주·분기·반기·연간 조회, 엑셀 양식·가져오기, 미래 손익 예상, 필요한 발주량 참고, 백업·복원, 기준 자료 관리다.

## 사용 범위와 시작 데이터

첨부된 전체 샘플 기록을 시작 자료로 준비한다. 엑셀과 JSON은 같은 자료이므로 한 형식만 기준으로 삼는다. 판매 6,112건, 비용 3,560건, 재고 변동 1,515건, 초기재고 및 기준 자료를 포함한다. 사용자가 직접 엑셀 파일을 가져오는 기능은 MVP에 포함하지 않는다.

자료 기간은 판매·비용 기준 2025-07-01~2026-09-18, 영업달력 기준 2025-07-01~2026-09-30이다. 미래 날짜에 판매 기록이 없다는 이유로 판매 0건으로 표시하지 않는다. 금액은 원·부가세 제외, 재료 수량은 g·ml·개다. 비용기록 3,560건은 월 비용을 일할 배분한 기록이며, 월비용계획과 중복으로 손익에 더하지 않는다.

자료의 메뉴는 아메리카노, 카페라떼, 바닐라라떼, 초콜릿라떼, 말차라떼, 레몬에이드, 크루아상, 치즈케이크다. 재료는 원두, 우유, 바닐라시럽, 초콜릿소스, 말차파우더, 레몬청, 탄산수, 냉동 크루아상, 냉동 치즈케이크, 포장컵세트, 디저트포장세트다. 자료의 판매 채널은 매장·포장이다. 시안의 다른 메뉴·재료·배달 채널은 사용하지 않는다.

## 기능 목록

### F1. 영업일·조회 기간 선택

**사용자가 하는 일과 입력:** 일일 입력에서 영업 기준일을 선택하거나 실적·손익에서 일별 또는 월별 기간을 선택한다.

**프로그램이 하는 일:** 해당 기간의 판매·비용·재고 기록을 집계하고, 기록 없음과 실제 0건을 구분한다. 2026년 9월은 9월 18일까지의 부분 기간으로 표시한다.

**화면과 파일에 나오는 결과:** 선택한 일자·월과 관련 기록·요약을 화면에 표시한다. MVP 파일 출력은 없다.

**오류나 예외가 있을 때의 동작:** 달력만 있고 판매가 없는 미래 날짜를 0건으로 처리하지 않는다. 기간이 잘못됐거나 자료가 없으면 사유를 표시한다.

**직접 확인할 방법:** 2026-09-18 일별·2026년 9월 월별 결과를 조회해 마지막 기록일과 부분 기간 표시를 확인한다.

### F2. 판매 기록 입력·수정·삭제

**사용자가 하는 일과 입력:** 영업일, 메뉴, 판매 채널, 수량, 단가, 할인액, 수수료를 기록한다. 목록 행에서 수정·삭제한다.

**프로그램이 하는 일:** 할인 후 판매액을 산출하고 수수료를 별도 값으로 저장한다. 할인 후 판매액 제안식은 수량 × 단가 − 할인액이다. 수수료는 메뉴 수익성·손익에서 한 번만 차감한다. 같은 날짜·메뉴·채널의 여러 입력 행은 개별 기록으로 저장하고 요약에서 합산한다. 수정·삭제 결과는 손익·수익성·재고에도 반영한다.

**계산 예시:** 2잔 × 4,000원, 할인 200원이면 할인 후 판매액은 7,800원이다. 수수료 120원은 별도 기록한다.

**화면과 파일에 나오는 결과:** 날짜별 판매 행과 기간 합계를 화면에 표시한다. MVP 파일 출력은 없다.

**오류나 예외가 있을 때의 동작:** 필수값 누락, 0 이하 수량, 음수 금액, 할인액 초과는 저장하지 않고 안내한다. 원가 계산에 필요한 자료가 없으면 판매는 저장하되 수익성·재고가 미완성임을 표시한다. 저장 실패 시 입력값을 보존한다.

**직접 확인할 방법:** 위 예시를 입력해 매출액·수수료를 확인하고 수량 수정·삭제에 따른 모든 결과 갱신을 확인한다.

### F3. 비용 기록 입력·수정·삭제

**사용자가 하는 일과 입력:** 날짜·비용 분류·금액을 필수로 입력한다. 상세 품목명·결제 수단·메모는 선택 입력으로 둔다. 기존 기록을 수정·삭제한다. 비용 분류는 첨부 자료의 분류를 기준으로 한다.

**프로그램이 하는 일:** 비용 기록을 일·월 손익에 반영한다. 비용 자료의 월비용계획과 일별 비용기록을 중복 합산하지 않는다.

**계산 예시:** 같은 기간 비용 기록 1,000원과 500원이면 비용 합계는 1,500원이다. 월비용계획이 같은 비용을 나타내면 실제 기록 합계에 다시 더하지 않는다.

**화면과 파일에 나오는 결과:** 비용 행과 분류별·기간별 합계를 화면에 표시한다. MVP 파일 출력은 없다.

**오류나 예외가 있을 때의 동작:** 필수값 누락·음수 금액·알 수 없는 분류는 저장하지 않고 안내한다. 판매기록 수수료와 비용 분류가 중복되면 이중 차감하지 않도록 알린다. 저장 실패 시 입력값을 보존한다.

**직접 확인할 방법:** 1,000원과 500원의 합계, 월비용계획 비중복, 수정·삭제 후 손익 갱신을 확인한다.

### F4. 메뉴별 수익성

**사용자가 하는 일과 입력:** 일별 또는 월별 결과를 선택하고 메뉴별 결과를 확인한다.

**프로그램이 하는 일:** 선택한 기준은 재료비·포장비·판매 수수료를 포함하고 임차료·인건비 등 공통비용은 메뉴에 배분하지 않는 것이다. 과거 판매에는 판매 당시 기록된 1개당 원가를 사용한다. 새 판매에는 판매일에 적용되는 레시피와 재료 가격을 사용한다. 재료별 포장 구매가격은 g·ml·개 기준 사용량으로 환산한다. 채널별 포장 레시피는 해당 채널 판매에만 적용한다.

**계산 예시:** 2잔 판매액 7,800원, 1잔당 재료비 500원·포장비 100원, 총 수수료 120원이면 공헌이익은 7,800 − 1,200 − 120 = 6,480원, 공헌이익률은 약 83.1%다. 공헌이익은 판매액에서 메뉴 직접비용을 뺀 값이다.

**화면과 파일에 나오는 결과:** 메뉴별 판매량·판매액·재료비·포장비·수수료·공헌이익을 화면에 표시한다. MVP 파일 출력은 없다.

**오류나 예외가 있을 때의 동작:** 판매·레시피·원가가 누락되면 계산 미완성을 표시하고 0원 원가로 간주하지 않는다. 판매액 0원인 경우 비율 계산 대신 계산 불가를 표시한다.

**직접 확인할 방법:** 위 예시 계산과 원가 누락 표시를 확인한다. 과거 기록 원가가 현재 가격에 따라 바뀌지 않는지 확인한다.

### F5. 일·월 손익

**사용자가 하는 일과 입력:** 일별 또는 월별 기간을 선택한다.

**프로그램이 하는 일:** 할인 후 판매액에서 메뉴별 재료비·포장비, 수수료, 해당 기간 비용기록을 차감한다. 월비용계획은 실제 기록에 추가하지 않는다. 비용 자료는 월 비용의 일할 배분이므로 결과를 ‘기록 기준 손익’으로 다루고 현금 지급액 또는 공식 재무제표라고 단정하지 않는다.

**계산 예시:** 판매액 7,800원 − 직접 원가 1,200원 − 수수료 120원 − 별도 비용기록 1,000원 = 손익 5,480원이다. 각 비용은 다른 항목에 이미 들어 있지 않아야 한다.

**화면과 파일에 나오는 결과:** 기간별 판매액, 메뉴 원가, 수수료, 비용기록, 손익을 화면에 표시한다. 부분 월과 기록 없음 상태를 구분한다. MVP 파일 출력은 없다.

**오류나 예외가 있을 때의 동작:** 월 계획과 일별 비용을 중복하지 않는다. 손익 누락 원가·비용을 0으로 바꾸지 않고, 음수 손익은 그대로 표시한다. 미마감일을 0원으로 표시하지 않는다.

**직접 확인할 방법:** 위 예시 손익 5,480원, 월계획 비중복, 부분 월·음수 결과를 확인한다.

### F6. 재고 변동·실사·잔량

**사용자가 하는 일과 입력:** 재료, 입고·폐기 종류, 수량, 날짜, 사유를 입력한다. 실사는 실제로 센 수량을 입력한다. 수량 단위는 재료 기준인 g·ml·개다.

**프로그램이 하는 일:** 입고는 더하고 폐기는 뺀다. 판매량에 선택 메뉴의 레시피 사용량을 적용해 재고를 자동 차감한다. 실사에서는 장부량과 실제 수량 차이를 표시하고 실측 수량을 이후 잔량의 기준으로 삼는다. 재고 기록에는 실측 수량과 조정량을 각각 보존한다.

**계산 예시:** 시작 1,000g + 입고 500g − 판매 사용 200g − 폐기 30g = 장부 1,270g. 실측이 1,260g이면 차이 −10g, 실사 후 잔량은 1,260g이다.

**화면과 파일에 나오는 결과:** 재료별 잔량·단위와 입고·폐기·실사 이력을 화면에 표시한다. 자동 부족 알림·발주량 계산은 MVP 파일/기능 범위에 포함하지 않는다.

**오류나 예외가 있을 때의 동작:** 음수·누락 수량이나 단위 불일치는 저장하지 않는다. ‘개’는 정수, g·ml는 소수 입력을 허용한다. 폐기량이 잔량보다 크면 저장을 막고 확인한다. 판매로 잔량이 부족해져도 실제 판매기록은 보존하고 부족 상태를 알린다. 레시피 누락 시 자동 차감 완료로 표시하지 않는다.

**직접 확인할 방법:** 위 입고·판매·폐기·실사 계산을 확인한다. 폐기 초과, 음수, 레시피 누락 시 처리를 확인한다.

### F7. 저장과 공통 검증

**사용자가 하는 일과 입력:** 각 판매·비용·재고 기록을 저장하고 다시 열어 확인한다.

**프로그램이 하는 일:** 저장된 기록을 유지하고 연결된 요약 결과를 갱신한다.

**화면과 파일에 나오는 결과:** 저장 성공은 화면에서 확인한다. MVP는 별도 파일을 생성하지 않는다.

**오류나 예외가 있을 때의 동작:** 오류가 있으면 성공 메시지를 보이지 않고 입력값을 보존해 재시도를 허용한다. 삭제 전 확인을 거친다. 빈칸과 값 0을 구분한다.

**직접 확인할 방법:** 각 유형 기록을 저장한 뒤 새로 열어 값이 유지되고 집계 결과도 갱신됐는지 확인한다.

## 수업 후 확장 기능

- 기간 확장: 주·분기·반기·연간 조회. 부분 연도와 자료 없는 기간을 구분한다.
- 엑셀: 판매·비용·재고 양식 내려받기 및 입력 데이터 가져오기. 파일 형식·ID·단위·필수값·중복 행 오류를 안내하며 잘못된 행을 조용히 누락하지 않는다.
- 손익 전망: 실제 기록과 예상값을 구분한다. 추천 계산 기준은 최근 영업일 평균 실적과 남은 영업일 및 미래 월비용계획이지만, 구현 전에 전망 기준을 확정한다.
- 발주량 참고: 현재 잔량, 납기·안전재고 일수, 예상 사용량을 이용한다. 예: 예상 사용 30개 + 안전재고 10개 − 현재 25개 = 부족 15개. 포장 단위가 10개면 2포장 참고. 실제 주문 전송은 하지 않는다.
- 백업·복원: 손상되거나 지원하지 않는 파일은 복원하지 않고 기존 데이터를 보존한다.
- 기준 자료 관리: 메뉴·재료·레시피·공급사·가격 이력을 관리한다. 가격·레시피 변경은 적용일 이후 결과에 반영하는 안을 사용한다.

## PRD 또는 시안에서 확정되지 않아 제외한 항목

시안의 현금 시재 확인, 브루잉 추출 수율, 배달 채널, 안전재고 경고 필터, 마진 개선 추천, EBITDA, PDF·CSV·엑셀 보고서 내보내기, POS 연동, 실제 발주 전송, 다매장 통합은 MVP에 포함하지 않는다.
